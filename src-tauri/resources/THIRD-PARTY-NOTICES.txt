Castaway - Third-Party Notices
==============================

Castaway's own code is licensed GPL-3.0-or-later (full text:
resources\LICENSE-Castaway.txt).

Castaway itself is a Tauri application. It bundles a separate program,
UxPlay, plus the runtime libraries and GStreamer plugins that UxPlay needs.
All of these are installed under the resources\uxplay folder next to
Castaway (resources\uxplay\uxplay.exe, resources\uxplay\*.dll and
resources\uxplay\gst-plugins\*.dll). Castaway runs uxplay.exe as a separate
process.

3. Rust crates and UI libraries linked into castaway.exe
--------------------------------------------------------
castaway.exe is built from Tauri 2 and about 470 other Rust crates from
crates.io (checked with `cargo metadata`). Their declared licenses are all
permissive or weak-copyleft: MIT, Apache-2.0 (some with the LLVM exception),
BSD-2/3-Clause, ISC, Zlib, Unicode-3.0, Unlicense, 0BSD, CC0-1.0 and MPL-2.0
(unmodified, source at https://crates.io). Most are dual-licensed "MIT OR
Apache-2.0", which Castaway uses under MIT. None is GPL-only. Per-crate
license texts are in each crate's published source. The web UI bundles only
Castaway's own code and the MIT/Apache-2.0 @tauri-apps JavaScript libraries.
